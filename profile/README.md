## About

**pilani.online** is an ecosystem of software products built to improve the academic and professional experience of students at **BITS Pilani, Pilani Campus**.

The platform focuses on creating reliable, data-driven applications that simplify student workflows through intuitive design and scalable engineering.

---

## Products

| Product | Description | Website |
|---------|-------------|---------|
| **pilani.online** | Central hub for all services | https://www.pilani.online |
| **curve.pilani** | Historical grade distributions and academic planning | https://curve.pilani.online |
| **handout.pilani** | Searchable repository of course handouts | https://handout.pilani.online |
| **ps1.pilani** | Analytics platform for Practice School I | https://ps1.pilani.online |
| **ps2.pilani** | Analytics platform for Practice School II | https://ps2.pilani.online |
| **prereq.pilani** | Interactive prerequisite graph visualizer | https://prereq.pilani.online |

## Design Principles

- Practical solutions to real student problems
- Fast, reliable and scalable systems
- Data-driven decision making
- Clean, intuitive user experience
- Long-term maintainability
