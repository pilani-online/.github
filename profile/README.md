## About

**pilani.online** is an ecosystem of student-built software designed to simplify academics and campus life at **BITS Pilani, Pilani Campus**.

The organization focuses on building reliable, data-driven tools that solve practical problems for students while remaining fast, simple and accessible.

---

## Projects

| Project | Description | Repository | Website |
|---------|-------------|------------|---------|
| **curve.pilani** | Historical grade distributions and academic planning | `pilani.online/grade-portal` | https://curve.pilani.online |
| **handout.pilani** | Searchable repository of course handouts | `pgoenka/handout.pilani` | https://handout.pilani.online |
| **ps1.pilani** | Analytics platform for Practice School I | `pgoenka/ps1.pilani` | https://ps1.pilani.online |
| **ps2.pilani** | Analytics platform for Practice School II | `pgoenka/ps2.pilani` | https://ps2.pilani.online |
| **prereq.pilani** | Interactive prerequisite graph visualizer | `pgoenka/prereq.pilani` | https://prereq.pilani.online |

## Principles

- Open source where possible
- Clean and maintainable architecture
- Fast, lightweight interfaces
- Practical utility for students
- Long-term maintainability
